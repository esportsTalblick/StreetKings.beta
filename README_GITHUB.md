# Street Kings Manager – GitHub Pages

## Upload
Den Inhalt dieses Ordners **direkt** in dein Repository hochladen:

```text
index.html
app.js
style.css
assets/
```

`index.html` muss auf Root-Ebene liegen.

## GitHub Pages
Repository → Settings → Pages → Deploy from branch → `main` → `/ (root)` → Save.

Danach liegt das Spiel unter:

`https://DEINNAME.github.io/DEINREPOSITORY/`

## Speicherung
Das Spiel speichert lokal im Browser (`localStorage`). Zusätzlich gibt es im Menü **Einstellungen** JSON-Export und -Import.

## Hinweise
Alle Teams und Sponsoren sind für dieses Browserprojekt fiktiv; Orte aus der Region dienen als Setting.
